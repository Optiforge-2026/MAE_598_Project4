# MAE 598 — Project 4: PDE-Constrained Design Optimization

## Bicycle Frame Optimization

**Selected Structure:** Bicycle Frame  
**Project Status:** In Progress

### Project Overview

For Project 4, we selected a **bicycle frame** as the structure for PDE-constrained design optimization.

The goal of this project is to develop and optimize a lightweight bicycle frame while maintaining adequate structural performance. A finite element model will be developed to evaluate the response of the frame under representative loading conditions.

### Planned Design Study

The bicycle frame will be modeled using **3D frame elements**. The primary design variables will include:

- Tube dimensions
- Selected joint positions
- Frame geometry parameters

The performance of each design will be evaluated using quantities such as:

- Total frame mass
- Structural stiffness
- Maximum stress
- Lowest natural frequency
- Structural stability and buckling

The optimization will seek to reduce the mass of the bicycle frame while satisfying the required structural performance constraints.

### Project Plan

The project will be developed progressively through the following stages:

1. Define the bicycle frame geometry, material, loads, and boundary conditions.
2. Develop the finite element analysis.
3. Verify the finite element solver using analytical benchmark problems.
4. Implement sensitivity and adjoint calculations.
5. Verify the calculated gradients using finite differences.
6. Perform gradient-based design optimization.
7. Evaluate buckling and stability behavior.
8. Compare the initial and optimized bicycle frame designs.
9. Develop an interactive 3D visualization of the results.
